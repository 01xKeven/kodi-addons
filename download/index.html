01xKeven Repository

Download the repository add-on (.zip) to install in Kodi and get access to all the add-ons.

Español · English

Download repository.01xkeven (.zip)

1. In Kodi go to Settings → Add-ons → Install from zip file and select the downloaded zip.
2. Then go to Install from repository → 01xKeven Repository and install the add-ons you want.
